# Reader quality rubric

Score each dimension 0–2. This is an editorial QA checklist, not a scientific guarantee.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Question fidelity | Misattributes or invents questions | Some inference unclear | Explicit, implied, and added context clearly separated |
| Answer relevance | Mostly generic background | Partly answers | Directly answers the participant's need |
| Option quality | No real comparison | Options incomplete | Feasible alternatives and meaningful trade-offs |
| Recommendation logic | Unsupported winner | Criteria partly clear | Criteria traceable; best-fit and alternatives explained |
| Evidence integrity | Snippets/inaccessible pages overstated | Some access gaps unclear | Access, relevance, and limitations transparent |
| Conceptual correctness | Major concepts conflated | Minor ambiguity | Distinctions correct and checked |
| Attribution | Personal view becomes consensus | Some attributions unclear | Speakers, owners, and disagreement represented faithfully |
| Readability | Jargon-heavy or bloated | Understandable with effort | Mixed-expertise readers can scan and understand |
| Action safety | Unsolicited trade signal or false certainty | Some wording too actionable | Decision support, not unasked trade instruction |

Suggested release gate: no zero in Question fidelity, Recommendation logic, Evidence integrity, Conceptual correctness, or Action safety. If a critical source is unavailable, mark the affected check BLOCKED rather than awarding a pass.
